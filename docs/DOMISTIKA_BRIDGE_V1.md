# Domistika → Auralith369 Creative Bridge v1

Auralith369 can now receive a local artwork package from Domistika when both applications are served from `michaelwave369.github.io`.

## Transfer package

The shared-origin browser package contains:

- a compressed WebP preview of the visible Domistika artwork;
- project name;
- source canvas dimensions;
- active Domistika symmetry mode;
- the user's Favorite Colors palette;
- protocol and timestamp metadata.

The package uses the localStorage key `parallax-creative-bridge-v1`. No artwork is uploaded by this bridge.

## Receiver modes

When Auralith369 opens at `#domistika-import`, the receiver offers:

- **Floating reference** — keeps the Domistika artwork visible beside the Auralith workspace;
- **Workspace backdrop** — places a low-opacity artwork field behind the visual-alchemy interface;
- **Download artwork** — saves the transferred WebP locally for ordinary import or archival use;
- **Open Domistika** — returns to the sketch studio;
- **Clear transfer** — removes the browser-local bridge package.

## Boundary

Bridge v1 is a visual-reference and atmosphere handoff. It does not silently inject pixels into an Auralith project or apply filters without the user's action. A deeper governed project-ingestion path can be added later after the Auralith project schema defines a stable imported-image contract.
